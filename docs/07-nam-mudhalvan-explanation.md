# Viva / Explanation Points

## Why Salesforce?

Salesforce provides a platform where data, security, automation and conversational AI can be connected in one system.

## Why VS Code?

VS Code is used to develop Salesforce DX source files and Lightning Web Components. Salesforce CLI authenticates the local project with the Salesforce org and deploys/retrieves metadata.

## Why HTML/CSS/JavaScript?

Lightning Web Components use HTML for structure, CSS for styling and JavaScript for client-side behavior.

## Why Flow?

Flow automates business processes without writing all business logic manually.

## Why Agentforce?

Agentforce provides a conversational interface through which users can ask shipment-related questions and trigger supported actions.

## Why Prompt Builder?

Prompt Builder defines instructions/context for AI responses so the assistant responds consistently and uses the intended business context.

## One-line architecture

LWC -> Apex -> Salesforce Objects -> Flow -> Agentforce/Prompt Builder
